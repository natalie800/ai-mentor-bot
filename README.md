# 🗺️ Treasure Map: AI Mentor Bot

**Treasure Map** — это Telegram-бот, который помогает абитуриентам и начинающим специалистам найти свой путь в IT и других профессиях.

## 🎯 Что умеет бот (В планах):
1. **Поиск вуза:** Помогает подобрать университет и специальность по предметам ЕГЭ и баллам.
2. **Поиск работы:** Подсказывает, как составить резюме и где искать первую стажировку.
3. **Адаптация:** Дает советы, как выжить в первый месяц на новой работе.
4. **Тренировка** Имитирует живое общение, задаёт каверзные вопросы.
5. **Персонализация** Даёт персонализированные рекомендации и индивидуальный план по улучшению.

## 🛠️ Стек технологий:
* Python
* aiogram (Telegram Bot API)
