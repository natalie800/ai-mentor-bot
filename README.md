#Treasure Map: AI Mentor Bot
Treasure Map — это Telegram-бот, который выступает в роли цифрового наставника для абитуриентов и начинающих специалистов. Бот помогает не только найти информацию о вузах и стажировках, но и подготовиться к реальным собеседованиям.

🎯 Возможности бота (Реализовано):
Информационный режим (Справочник):

Поиск вузов по направлению «Информационная безопасность» с проходными баллами и ссылками на официальные сайты.

Поиск актуальных стажировок в IT-сфере.

База знаний: раздел с реальными отзывами студентов/сотрудников и академической литературой.

Режим Тренажёра:

Имитация живого общения с наставником (бот задаёт 3 проблемных вопроса по сценарию собеседования).

Анализ ответов на типичные ошибки (например, упоминание денег как главной мотивации или отсутствие портфолио).

Выдача персональных рекомендаций и индивидуального плана подготовки по итогам тренировки.

Безопасность: защита от некорректного ввода (бот не ломается при отправке стикеров или фото).

🛠️ Стек технологий:
Язык: Python 3

Библиотеки: pyTelegramBotAPI (telebot), python-dotenv

Хранение данных: JSON (database.json)

📂 Архитектура проекта:
main.py — основной код бота, обработка кнопок и логика проверки ответов.

database.json — база знаний, содержащая сценарии поступления, стажировок и вопросы для тренажёра.

🚀 Как запустить проект локально:
Установите зависимости:

bash
pip install -r requirements.txt
Создайте файл .env в корневой папке проекта.

Получите токен у @BotFather в Telegram и добавьте его в .env:

text
BOT_TOKEN=ваш_токен_здесь
Запустите бота:

bash
python main.py
⚠️ Дисклеймер:
Рекомендации носят ознакомительный характер и не заменяют официальные требования вузов и работодателей.
